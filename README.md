# devclub-mobile-app

> Aplicativo mobile para estudos do clube de desenvolvimento com UI moderna e navegação nativa.

## Problema

Aplicativo mobile para estudos do clube de desenvolvimento com UI moderna e navegação nativa.

## Solução

React Native com Expo, Gluestack UI e NativeWind para componentes acessíveis e layout responsivo em iOS e Android.

## Stack

- React Native
- Expo
- TypeScript
